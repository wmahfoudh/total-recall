# Records

One-off records: a pasted log, a study, a hunt, a spec or a plan written
by a skill. Each file is listed here with its date and a line on what it
holds. `tools/doc-check.py` skips this folder: a record is kept as it
was received, with one exception: the name of the reference project,
the path of its folder, the path of this machine and the session
scratchpad were replaced by `<the reference project>`, `<the reference
folder>`, `~` and `<the session scratchpad>` on 07/10/2026, the user's
word.
