# Records

One-off records: a pasted log, a study, a hunt, a spec or a plan written
by a skill. Each file is listed here with its date and a line on what it
holds. `tools/doc-check.py` skips this folder: a record is kept as it
was received, with one exception: the name of the reference project,
the path of its folder, the path of this machine and the session
scratchpad were replaced by `<the reference project>`, `<the reference
folder>`, `~` and `<the session scratchpad>` on 07/10/2026, the user's
word.

| File | Date | What it holds |
|---|---|---|
| `2026-10-07-design.md` | 07/10/2026 | The spec of the skill and of the memory system, approved by the user, written with the brainstorming skill. Names the reference project |
| `2026-10-07-plan.md` | 07/10/2026 | The implementation plan, thirteen tasks, written with the writing-plans skill and approved |
| `2026-10-07-ledger.md` | 07/10/2026 | The ledger of the build: the rulings made during the tasks, with their cost if wrong |
| `2026-10-07-review.md` | 07/10/2026 | The report of the fresh reviewer: four Important findings, fixed the same day, and thirteen Minor ones, item 2 of the Roadmap |
