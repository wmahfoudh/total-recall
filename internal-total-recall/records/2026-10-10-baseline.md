# The cost of a start, before Phase 03

Measured 10/10/2026, Task 32, before any change of Phase 03. The
benchmark of the phase measures the same files the same way at its end.

## The files measured

The folder as committed in `b315d2c` (the last commit that changed it
is `887ca7c`), and the templates of `skill/templates/` in the same
commit. Phase 02 was the open phase.

## The method

- `wc -w` on each file read at each start.
- `python3 internal-total-recall/tools/doc-check.py --size internal-total-recall`
  for the total the tool reports.
- The tokens: a fresh session, "let's start", then `/context`, run by
  the user. The figure is added below when it comes.

The start routine asks for the preamble and the current task of the
phase file. The read tool returns the whole file unless it is given a
range, so a start reads between 298 words and the whole file. The
global rules file is loaded by Claude Code on this machine only, and a
start here reads about 8,300 words with it.
